# FOUR x SEVEN - App & Game Builder

## 🌍 Build Android Apps from HTML Code

Turn your HTML websites and games into real Android APK files.

### Features

- ✅ Write HTML/CSS/JavaScript code
- ✅ Upload existing HTML files
- ✅ Live preview
- ✅ Save and load projects
- ✅ Build APK files
- ✅ Free for everyone
- ✅ No sign-up required

### How to Use

1. **Write** - Write your HTML/CSS/JavaScript in the code editor
2. **Upload** - Or upload an existing HTML file
3. **Preview** - See your app live in the preview window
4. **Build** - Click BUILD APK to create your Android app
5. **Download** - Download your APK and install on your phone

### Tech Stack

- HTML5, CSS3, JavaScript
- GitHub Actions
- PWABuilder
- Vercel
